# Ticket Board 画風設定

image-generation skill が読む、このプロジェクト固有の画像制作ルール。

## 今の画風

- **名前:** フラットなカンバン風（`flat-kanban`）
- **採用日:** 2026-11-16
- **画風の記述:** 青系(#0c66e4 付近)の角丸の四角を地にした、フラットで単純なアプリアイコン。白いチケットカードが縦に並ぶ3列のカンバンボードを、太く大きな図形だけで表す。
- **塗り方:** 各面は単色のベタ塗り。グラデーション・光沢・影・質感なし。
- **線:** 輪郭線は使わない。面の色の差だけで形を作る。
- **基準画像（画風参照）:** なし（初回。現行の SVG 案は `index.html` の `<link rel="icon">` にある）
- **色ムラ検査:** 使わない（基準画像がまだ無い。確定後に基準にする）
- **禁止:** 細い線、小さな文字、細かい飾り、グラデーション、影、3D 風の立体表現。16px に縮めたとき潰れるもの。

## 置き場と命名

| 用途 | WIP | 確定先 | 寸法・画角 | 透過 |
|---|---|---|---|---|
| タブのアイコン | `.claude/imagegen-wip/icon_vN.png` | 組み込み用に 32×32 へ縮小し `index.html` に data URI で埋め込む（元の大きな PNG は `.claude/imagegen-wip/` に残す） | 1024px 四方の正方形、中央に余白 5% 程度 | 角丸の外側を透過 |

## 反映手順

確定した PNG を 32×32（必要なら 64×64）に縮小し、base64 の data URI にして `index.html` の `<link rel="icon" type="image/png" href="...">` を差し替える。別ファイルは増やさない（共有フォルダへコピーするのが `index.html`・`app.js`・`style.css` の3つだけのため）。

- 実画面の確認: 16px・32px に縮小した一覧を作って目視する。タブ固定時の見え方は利用者に Chrome / Edge で確かめてもらう。

## 注意点

- `file://` で動く・ビルドなし・別ファイルを増やさないが、このプロジェクトの決まり（`CLAUDE.md`）。
- 16px で識別できることが最優先。細部より、色と大きな形で「ボード」と分かること。
