# Ticket Board

サーバー不要で動く、チーム向けのチケット管理ツールです(Jira のようなカンバンボード)。
HTML / CSS / JavaScript の3ファイルだけでできており、インストールもビルドも不要です。

データはチームの共有フォルダ(Box Drive、Google Drive for desktop、社内ファイルサーバーなど、PC 上でフォルダとして開けるもの)に JSON ファイルとして保存します。全員が同じフォルダを選ぶことで、チケットが共有されます。

## 必要なもの

- Chrome または Edge の最新版(Firefox / Safari は非対応)
- チーム全員が読み書きできる共有フォルダ

API キーの発行やアプリ登録は不要です。ブラウザ標準の File System Access API を使い、フォルダ選択ダイアログで許可するだけで動きます。

## まず1人で触ってみる

1. このリポジトリをクローン(またはダウンロード)します。
2. `index.html` を Chrome か Edge で開きます(ダブルクリックで構いません)。
3. 名前を登録します(端末名は自動で入ります。変えても構いません)。利用者ID は自動で作られます。
4. 「お試しモード」を押します。

お試しモードのデータはそのブラウザの中だけに保存され、他の人とは共有されません。

## チームで使う

1. 共有フォルダの中に、このツール用のフォルダを1つ作ります(例: `TicketBoard`)。
2. `index.html`・`app.js`・`style.css` をそのフォルダに置きます。
3. 各メンバーが `index.html` を開き、プロフィールを登録して「フォルダを選ぶ」で同じフォルダを選びます。

```
共有ドライブ/
└─ TicketBoard/
   ├─ index.html  app.js  style.css   ← アプリ本体
   ├─ config.json                     ← 以下は初回起動時に自動で作られる
   ├─ tickets/
   ├─ attachments/
   ├─ users/
   ├─ logs/
   └─ templates/
```

ブラウザを開き直したときは、確認のため「再接続」ボタンを1回押す必要があります。

お試しモードから切り替えるときは、「設定」→「保存先フォルダを切り替える」を押します。

## できること

| 機能 | 内容 |
|---|---|
| チケット | 種別・優先度・担当者・期限・ラベル・プロジェクト・説明・コメント・変更履歴。説明は押すと編集でき、URL やキーはリンクとして表示。自分のコメントは編集・削除できる。「作成して続ける」で何件も続けて登録できる |
| プロジェクト | 1つのボードの中でチケットを分ける単位。チケットごとに1つ選ぶ。キー(`TK-12`)はプロジェクトをまたいで通し番号。「プロジェクト」画面で、ステータス・期限・進み具合(完了数/全体)・期限切れの数・説明を一覧でき、名前を押すとそのプロジェクトのボードが開く。「＋ プロジェクトを作成」でプロジェクトテンプレートを選ぶと、そのチケットもまとめて作られる。名前を変えると、付いているチケットのプロジェクトも書き換わる。チケットが無いプロジェクトだけ削除できる |
| プロジェクトのステータス | 設定画面で決める(既定は 計画中・進行中・保留・完了。最後の行が完了扱い)。完了したプロジェクトは、プロジェクト画面(「完了したプロジェクトも表示」で見られる)・プロジェクトの選択肢・ボードとリストのチケットから外れる。プロジェクト画面から開けば、そのチケットも見られる |
| テンプレート | 設定画面で作る。プロジェクトテンプレートは複数のチケット、チケットテンプレートは1枚分(タイトル・種別・優先度・説明・ラベル・チェックリスト)を持つ。チケットテンプレートはチケット作成画面で選ぶ。同じテンプレートを2人が同時に編集すると、後から保存したほうが残る |
| サブチケット | チケットの詳細画面から、その下にサブチケットを作れる。サブチケットは普段はボード・リストに出さず、親のカードに「サブ 完了数/全体」を表示。サブは親の詳細画面から開く。絞り込みバーの「サブチケットを表示」にチェックを入れると、親のキー(「↳ TK-3」)付きでボード・リストにも並ぶ |
| チェックリスト | チケットの中の ToDo。カードに「☑ 完了数/全体」を表示 |
| 関連チケット | 親(サブチケットにする)・ブロックしている/されている・関連。未完了のチケットにブロックされていれば ⛔ を表示 |
| キーの自動リンク | 説明やコメントに `TK-12` のようにキーを書くと、押してそのチケットを開ける |
| 新着 | 自分に関係するチケット(担当・報告者・コメントした・チェック項目を足した)を他の人が更新すると、● と右上の「🔔 n」で知らせる |
| ボード | ステータスごとの列。カードをドラッグしてステータスを変更(直後に出る「元に戻す」で戻せる)。期限切れは赤、3日以内は黄色 |
| リスト | 一覧表示。列見出しのクリックで並べ替え |
| 検索・絞り込み | キーワード(コメントも対象)、プロジェクト、担当者、種別、優先度、ラベル(カードのラベルを押しても絞り込める)、自分の担当のみ、新着のみ。サブチケットを表示(「✕ クリア」では外れない)。表示と絞り込みはブラウザに記憶される。絞り込み中は「絞り込み中 ✕ クリア」が出る |
| 添付ファイル | チケットごとのフォルダに保存。ドラッグ&ドロップで追加 |
| 関連リンク | Box の共有リンクなどの URL を登録 |
| 操作ログ | 誰が・いつ・どの端末で・何をしたかを月別・ユーザー別に表示 |
| メンバー | 利用者の一覧、初回・最終アクセス、担当中の件数 |
| 設定 | ボード名、チケットキーの接頭辞、ステータス、種別、プロジェクトのステータス、テンプレート |
| バックアップ | チケット・設定・メンバー・添付を1つの JSON ファイルに保存。読み込むと今のデータに追加(上書きしない)。テンプレートは含まない |

他のメンバーの変更は20秒ごとに自動で反映されます。右上の「↻」で今すぐ再読み込みできます。

### キーボードショートカット

| キー | 動作 |
|---|---|
| `C` | チケット作成 |
| `/` | 検索欄へ移動 |
| `J` / `K` | 次 / 前のチケットを選ぶ(ボード・リスト) |
| `Enter` | 選んだチケットを開く |
| `E` | 説明を編集(チケットの詳細で) |
| `Ctrl+Enter` | コメントを送信・説明を保存 |
| `Esc` | ダイアログを閉じる(説明やコメントの編集中は、編集を終える) |
| `?` | ショートカットの一覧を表示 |

入力欄にカーソルがあるときは、`Ctrl+Enter` と `Esc` 以外は反応しません。

### お試しモードのデータをチームのフォルダに移す

1. お試しモードで「設定」→「バックアップを保存」を押します。
2. 「保存先フォルダを切り替える」で、チームのフォルダに接続します。
3. 「設定」→「バックアップを読み込む」で、保存したファイルを選びます。

キーが既存のチケットと重なるものは、読み込むときに番号を振り直します。

### 新着の既読について

既読かどうかは、そのブラウザの中にだけ記録されます(共有フォルダには書きません)。別の PC で開くと、既読の状態は引き継がれません。

### 添付ファイルと資材の連携

チケットの添付は `attachments/<チケットID>/` に保存されます。画面から追加しても、エクスプローラーでこのフォルダに直接ファイルを置いても、チケットの添付一覧に表示されます。

別の場所にある資材は、共有リンクの URL を「関連リンク」に登録してください。

## 知っておくべき制限

- **利用者の情報は自己申告です。** 名前・端末名は各自が入力したもので、認証はありません。ブラウザからは PC 名・Windows のユーザー名・IP アドレスを取得できないため、端末名に自動で入るのはブラウザと OS の種類(例: Edge / Windows 11)だけです。
- **利用者ID はブラウザごとに作られます。** 別の PC やブラウザでも同じ人として使うときは、元のブラウザの「設定 → 利用者ID」に出る ID を、新しい方の同じ欄に入力して引き継いでください。ブラウザのデータを消すと ID も消えるので、ID を控えておいてください。以前の版でメールアドレスを登録した人は、そのメールアドレスが ID として使われ続けます。
- **操作ログは目安です。** ログは共有フォルダ内のファイルなので、フォルダに書き込める人なら書き換えられます。厳密な監査が必要な場合は、共有ドライブ側のアクセスログやバージョン履歴を使ってください。
- **アクセス制御は共有フォルダの権限で行います。** フォルダを開ける人は全員、すべてのチケットを読み書きできます。
- **同じ項目の同時編集は後勝ちです。** 別々の項目の編集は両方残ります。
- **チケット番号が一時的に重複することがあります。** 2人がほぼ同時に作成すると、同じ番号のチケットが2件できます。ファイルは別なので、データは失われません。後から作られた方は、作成した人の画面で自動的に番号が振り直されます(変更履歴に残ります)。振り直されるまでの間、カードに「⚠ 重複」が出ます。同期ドライブの競合コピー(作成日時とタイトルが同じもの)は振り直さないので、内容を見比べて片方をアーカイブしてください。
- **チケットは削除できません。** アーカイブのみで、「アーカイブを表示」から戻せます。
- **添付を開くとき**、画像・PDF・テキストは別タブで開き、それ以外はダウンロードになります。

## 動作確認の状況

| 項目 | 状況 |
|---|---|
| お試しモードでの全機能(`index.html` を直接開いた場合) | 自動テストで確認済み(Linux のヘッドレス Chromium) |
| 実際のフォルダを選んでの読み書き | 未確認 |
| Box Drive / Google Drive for desktop / ネットワークドライブ上での動作 | 未確認 |

Chrome はファイルを書き込むとき、一時ファイル(`.crswap`)を作ってから差し替えます。同期ドライブやネットワークドライブがこの動きと相性が悪い場合、書き込みエラーになる可能性があります。チームで使い始める前に、2台の PC で同じチケットを編集して確かめてください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「フォルダを選ぶ」ボタンが出ない | Chrome か Edge の最新版で開いてください |
| フォルダ選択が拒否される | 会社のブラウザポリシーで File System Access API が禁止されている可能性があります。管理者に確認してください |
| 毎回「再接続」を求められる | ブラウザの仕様です。許可ダイアログで「毎回許可する」を選べる場合は、選ぶと省略できます |
| 他の人の変更が見えない | 共有ドライブの同期が終わっているか確認し、「↻」を押してください |
| 同じチケットが2つ見える(「⚠ 重複」が出る) | 同期ドライブが競合コピーを作った可能性があります。内容を見比べて片方をアーカイブしてください |
| 書き込みエラーが出る | エラー文と、選んだフォルダの種類(同期ドライブ、ネットワークドライブなど)を控えて報告してください |
